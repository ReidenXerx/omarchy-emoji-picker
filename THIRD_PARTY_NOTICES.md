## Unicode emoji data

`data/emoji.json` takes its emoji list, grouping, order and skin-tone variants from
`emoji-test.txt`, Unicode Emoji 16.0.

- Source: https://www.unicode.org/Public/emoji/16.0/emoji-test.txt

## Unicode CLDR annotations

The English, Ukrainian and Russian names and keywords in `data/emoji.json` and
`data/symbols.json` come from the CLDR annotations.

- Source: https://github.com/unicode-org/cldr-json, revision `1aaabe99aa65`
  - `cldr-annotations-full/annotations/{en,uk,ru}/annotations.json`
  - `cldr-annotations-derived-full/annotationsDerived/{en,uk,ru}/annotations.json`
- License: Unicode License V3, `LICENSES/Unicode-3.0.txt`
- Copyright © 1991-2026 Unicode, Inc.

Symbols that CLDR does not name use their Unicode character name, taken from Python's
`unicodedata` module (Unicode Character Database, same license).

## Kaomoji

`data/kaomoji.json` comes from emoticon-data. Its tags were grouped into tabs and given
Ukrainian and Russian search words; the kaomoji themselves are unchanged.

- Source: https://github.com/w33ble/emoticon-data, revision `92b6211ec2a9`
- License: MIT, `LICENSES/emoticon-data-MIT.txt`

GIF search is powered by KLIPY. No KLIPY content ships with this plugin. Results are
fetched live with the user's own API key, under the KLIPY API Terms:
